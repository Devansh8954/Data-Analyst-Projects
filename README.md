## 📋 About This Repository

This repository showcases hands-on **data analytics projects** built with industry-standard tools. Each project takes a real-world dataset through the complete data analysis pipeline: cleaning, exploration, modeling, and visualization.

---

## 📊 Projects

### 🏢 HR Analytics Dashboard
An interactive **Human Resources Analytics Dashboard** built in Power BI that provides deep insights into workforce metrics, attrition patterns, and employee performance.

**Dashboard Highlights:**
| Metric | Insight |
|---|---|
| 📉 Attrition Analysis | Department-wise attrition rates & trends |
| 👥 Demographics | Age, gender & education distribution |
| 💰 Compensation | Salary bands vs. performance correlations |
| ⭐ Satisfaction | Employee satisfaction scores by role |
| 📅 Tenure Analysis | Average years at company by department |

**Tools Used:** `Power BI` `DAX` `Data Modeling` `Excel`

📁 [`HR Analysis/`](./HR%20Analysis/)
- 📄 [`HR Analytic Dashboard.pdf`](./HR%20Analysis/HR%20Analytic%20Dashboard.pdf) — Exported report
- 📊 [`PowerBI.pbix`](./HR%20Analysis/PowerBI.pbix) — Interactive Power BI file

## 🚀 Getting Started

### Viewing the Power BI Dashboard

1. **Download** [Power BI Desktop](https://powerbi.microsoft.com/en-us/desktop/) (free)
2. **Clone** this repository:
   ```bash
   git clone https://github.com/Devansh8954/Data-Analyst-Projects.git
   ```
3. **Open** the `.pbix` file in Power BI Desktop
4. **Explore** the interactive dashboard filters and drill-throughs

### Viewing the PDF Report
Open `HR Analytic Dashboard.pdf` in any PDF viewer for a static snapshot of the dashboard.
